## TÓM TẮT BÁO CÁO (VIETNAMESE ABSTRACT)

Xu thế chuyển đổi xanh trong giao thông đô thị và sự phát triển mạnh mẽ của phương tiện giao thông thuần điện (EV) đang đặt ra nhu cầu cấp thiết về các mô hình kinh tế chia sẻ và đồng sở hữu tài sản giá trị cao nhằm tối ưu hóa chi phí đầu tư ban đầu và chi phí vận hành. Báo cáo thực tập tốt nghiệp này trình bày toàn diện quá trình khảo cứu, phân tích nghiệp vụ, thiết kế kiến trúc và hiện thực hóa hệ thống phần mềm **EVShare 3D** – nền tảng quản trị và vận hành xe điện đồng sở hữu tích hợp không gian Web 3D tương tác.

Hệ thống giải quyết triệt để các thách thức cốt lõi của bài toán đồng sở hữu bao gồm: quản trị minh bạch tỷ lệ cổ phần (tổng luôn đạt chuẩn 100%), giải quyết xung đột lịch đặt xe (Booking Conflict Prevention), kiểm soát chặt chẽ chu trình bàn giao - trả xe thông qua kiểm tra kỹ thuật và bản đồ hóa hư hỏng 3D trực quan (3D Damage Mapping), quản trị tổn hao sạc điện và hạch toán tồn kho năng lượng theo phương pháp giá bình quân gia quyền (Weighted Average Cost), cùng cơ chế phân bổ nghĩa vụ chi phí trực tiếp (Direct Expense Allocation) ứng dụng thuật toán phần dư lớn nhất Hare-Niemeyer. 

Về mặt công nghệ, hệ thống ứng dụng kiến trúc phân tầng chuẩn mực với Backend xây dựng trên nền tảng Java 21, Spring Boot 3.3.4, Spring Security, JWT và Hibernate ORM liên kết cơ sở dữ liệu MySQL 8.0 (được phiên bản hóa qua 46 bước di chuyển Flyway); Frontend được phát triển bằng React 18, TypeScript, Vite, kết hợp thư viện đồ họa WebGL Three.js (r173) và React Three Fiber/Drei nhằm tạo lập không gian Virtual Garage 3D thuần nhất (Pure 3D-First Experience). 

Kết quả đề tài đã hoàn thiện một hệ thống phần mềm hoàn chỉnh, đáp ứng đầy đủ các yêu cầu chức năng cho 3 nhóm tác nhân Quản trị viên (ADMIN), Nhân viên vận hành (STAFF) và Chủ đồng sở hữu (CO_OWNER). Báo cáo cũng chỉ rõ các giới hạn kỹ thuật hiện tại như việc tích hợp cổng thanh toán và chữ ký số ở chế độ mô phỏng DEMO, cơ chế sạc dựa trên mô hình toán chưa kết nối thiết bị phần cứng IoT thực tế, từ đó vạch ra định hướng phát triển hoàn thiện trong tương lai.

**Từ khóa**: *Đồng sở hữu xe điện; Web 3D; Three.js; React Three Fiber; Spring Boot; Tồn kho năng lượng; Phân bổ chi phí; Digital Twin; Bản đồ hóa hư hỏng 3D.*

## ABSTRACT (ENGLISH)

The accelerating global transition toward sustainable urban mobility and pure electric vehicles (EVs) has fostered a growing demand for shared-economy frameworks and fractional co-ownership of high-capital transportation assets to alleviate heavy upfront acquisition costs and ongoing maintenance burdens. This graduation internship report comprehensively presents the requirement analysis, architectural system design, software engineering methodology, and implementation of **EVShare 3D** – an intelligent Web-based 3D platform dedicated to electric vehicle co-ownership management and operational workflows.

The system thoroughly resolves pivotal real-world co-ownership challenges, including rigorous co-ownership equity management (enforcing invariant 100% aggregate share total), automated booking time conflict prevention, comprehensive vehicle handover and return lifecycles corroborated by standardized technical inspection checklists, spatial 3D vehicle damage mapping, physical battery charging efficiency loss modeling, vehicle energy inventory management utilizing the weighted-average cost (WAC) formula, and direct financial expense allocation governed by the Hare-Niemeyer largest-remainder algorithm.

Technologically, the platform adopts an enterprise-grade layered architecture: the backend is engineered utilizing Java 21, Spring Boot 3.3.4, Spring Security, JWT-based token authentication, and Spring Data JPA / Hibernate mapped to a relational MySQL 8.0 database (version-controlled through 46 structured Flyway migrations); the frontend is powered by React 18, TypeScript, Vite, Zustand state management, TanStack Query, and a high-performance WebGL 3D rendering pipeline based on Three.js (r173) and React Three Fiber / Drei, delivering a seamless, immersive Virtual Garage 3D environment.

The research delivers an operational, end-to-end full-stack software system catering to three distinct roles: System Administrator (ADMIN), Operations Staff (STAFF), and Co-Owner (CO_OWNER). The report candidly acknowledges verified technical boundaries—such as simulated DEMO financial settlement, mock digital contract signing, and software-modeled charging sessions absent live hardware IoT telemetry—establishing a solid academic foundation and actionable roadmap for future production enhancement.

**Keywords**: *Electric Vehicle Co-Ownership; Web 3D; Three.js; React Three Fiber; Spring Boot; Energy Inventory; Expense Allocation; Digital Twin; 3D Damage Mapping.*

| **LCP** | Largest Contentful Paint | Chỉ số đo lường thời gian hiển thị phần tử nội dung lớn nhất |
| **ODO** | Odometer | Chỉ số đồng hồ đo tổng quãng đường đã lăn bánh của phương tiện (km) |
| **ORM** | Object-Relational Mapping | Kỹ thuật ánh xạ giữa các đối tượng mã nguồn và bảng cơ sở dữ liệu |
| **RBAC** | Role-Based Access Control | Cơ chế kiểm soát quyền truy cập dựa trên vai trò người dùng |
| **REST** | Representational State Transfer | Phong cách kiến trúc mạng định hướng tài nguyên |
| **SOC** | State of Charge | Tỷ lệ phần trăm dung lượng pin khả dụng hiện tại (%) |
| **SOH** | State of Health | Tỷ lệ phần trăm dung lượng pin còn lại so với dung lượng xuất xưởng (%) |
| **SPA** | Single Page Application | Ứng dụng web đơn trang nạp động không cần tải lại trang |
| **UML** | Unified Modeling Language | Ngôn ngữ mô hình hóa thống nhất trong công nghệ phần mềm |
| **WAC** | Weighted Average Cost | Phương pháp tính giá bình quân gia quyền trong quản trị kho |
| **WebGL** | Web Graphics Library | Thư viện kết xuất đồ họa 3D tăng tốc phần cứng trên trình duyệt Web |
